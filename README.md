# Banking Customer Support AI Agent — Multi-Agent Architecture

**Applied Generative AI · Course-End Project 3**

A multi-agent GenAI system for banking customer support. Each incoming message is
**classified** and **routed** to a specialized agent that crafts a personalized response
and manages support tickets in a database. Built with **LangChain + Groq** (`openai/gpt-oss-20b`)
and a **SQLite** `support_tickets` database — **one free key, no embeddings needed.**

## Files

| File | Purpose |
|------|---------|
| `BankingSupportMultiAgent.ipynb` | Full notebook — all steps, self-contained, runs top-to-bottom. **Primary deliverable.** |
| `banking_core.py` | The engine: DB layer, the four agents, supervisor, logging, evaluation. Imported by the app. |
| `app.py` | Streamlit dashboard — routing, classification/response/DB view, tickets, evaluation, logs & debugging. |
| `Data/init_db.py` | Creates and seeds the `support_tickets` SQLite database. |
| `Data/support_tickets.db` | The support database (SQLite). |
| `Data/agent_logs.json` | Agent-action log (created at runtime). |
| `requirements.txt`, `.env.example` | Setup. |

> All customers, tickets, and messages are **fictional** sample data.

## The agents (Part 1)

- **Classifier Agent** — routes a message to *Positive Feedback*, *Negative Feedback*, or *Query*.
- **Feedback Handler Agent** — *positive* → warm, personalized thank-you; *negative* → generate a unique 6-digit ticket, insert an unresolved ticket into `support_tickets`, and return an empathetic message with the ticket number.
- **Query Handler Agent** — extract the ticket number from the message, query the DB, return its status.
- **Supervisor Agent** — orchestrates classify → route → respond, logging every step.

## Setup

Run from inside this folder, in a terminal. A free Groq key: https://console.groq.com/keys

```bash
python3 -m venv .venv && source .venv/bin/activate   # optional
pip install -r requirements.txt
cp .env.example .env        # then edit .env and set GROQ_API_KEY
```

(Optional — reset the database to a clean seed:)

```bash
python Data/init_db.py
```

## Run the notebook

Open `BankingSupportMultiAgent.ipynb` and *Run All*. The agent cells require the Groq key.

## Run the Streamlit app

```bash
streamlit run app.py
```

Streamlit prints a local URL (usually `http://localhost:8501`). Try the **scenario buttons**
on the Assistant tab (positive / negative / query), then watch the **Tickets** and
**Logs & Debugging** tabs update. Example query: *"Could you check the status of ticket 650932?"*
→ "Your ticket #650932 is currently marked as: Resolved."

## Note

This is a demonstration system with fictional data. Responses are generated by an LLM and
should be reviewed before any real customer-facing use.
